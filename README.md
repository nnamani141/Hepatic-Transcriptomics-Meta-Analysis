# Hepatic Transcriptomics Meta-Analysis
Unified repository combining upstream RNA-Seq analysis, sex-stratified human and mouse hepatic transcriptomic meta-analyses, and cross-species comparative visualizations across metabolic dysfunction-associated steatotic liver disease (MASLD / MASH) progression.

## Repository Structure

Hepatic-Transcriptomics-Meta-Analysis/
── RNA-Seq-Analysis-main/     # Upstream RNA-Seq processing, normalization, and differential expression workflows
── Mus-Meta-Analysis-main/      # Preclinical mouse (Mus musculus) hepatic transcriptomic meta-analysis
── Human-Meta-Analysis-main/    # Human cohort meta-analysis stratified by sex and disease stage (Steatosis, MASH, Progression, Fibrosis)
── Cross-species-plot-main/     # Cross-species comparative analyses and visualization scripts
